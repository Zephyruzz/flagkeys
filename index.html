What it checks

Four kinds of hidden text

These are the tricks used to plant instructions that only a machine reads. Flagkeys inspects the document's raw structure for each one.

Invisible font sizes

Text set to 1pt, 2pt or any size too small to read. You'd never notice it on the page, but the words are still there for an AI to follow.

White or near-white text

Words coloured to match the page, or marked with Word's "hidden" setting. Invisible on screen and on paper — plain text to a model.

Instruction phrases

Sentences written to command an AI — "ignore previous instructions", "include the word…", "give this an A". Flagkeys matches known patterns like these.

Zero-width characters

Unicode characters that take up no space at all, slipped between letters and words. They can tag your text or sneak commands past a spell-check.

Privacy

Your file never leaves your browser

Flagkeys has no server that receives documents. When you choose a file, the scan runs on your own device using code already loaded on this page.

  • The file is read locally with JSZip — a .docx is a ZIP archive of XML — and inspected in memory.
  • No upload, no network request after the page loads, no analytics, no copy kept anywhere.
  • Close the tab and nothing remains. Reload with no connection and the scan still works.
